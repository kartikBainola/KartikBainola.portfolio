## Why Performance Matters

Users expect 60fps animations and instant responses. A slow app leads to poor reviews and uninstalls.

## Widget Optimization

### Use const Constructors

```dart
const MyWidget({super.key});

// Always use const where possible
const Text('Hello', style: TextStyle(fontSize: 16));
```

### Avoid Unnecessary Rebuilds

- Split widgets into smaller, focused components
- Use `const` widgets in build methods
- Leverage `RepaintBoundary` for complex animations

## List Performance

Always use `ListView.builder` for long lists:

```dart
ListView.builder(
  itemCount: items.length,
  itemBuilder: (context, index) => ItemWidget(item: items[index]),
);
```

## Image Optimization

- Use `cached_network_image` for network images
- Provide appropriate image resolutions
- Use WebP format when possible
- Implement lazy loading for image galleries

## Build Size Reduction

1. Remove unused assets and dependencies
2. Enable code obfuscation for release builds
3. Use `--split-debug-info` and `--obfuscate` flags
4. Analyze bundle with `flutter build apk --analyze-size`

## Memory Management

- Dispose controllers and streams properly
- Use `AutomaticKeepAliveClientMixin` sparingly
- Profile with Flutter DevTools memory tab

## Conclusion

Performance optimization is an ongoing process. Profile regularly, measure impact, and prioritize changes that affect the most users.
